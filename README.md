# Сервис управления производственными заданиями
Работа с FastAPI находится в main.py
## Краткое описание
Сервис управления производственными задачами (Job): доменная логика + REST API поверх неё + хранение в PostgreSQL. 
> Могла пропустить какие-то детали, уникальные для питона (мало опыта с ним + пришлось быстро учиться)

### Ошибки
Для ошибок реализовала наследование. 
- JobServiceError - базовый класс
- JobNotFoundError - работа не найдена (код 404)
- InvalidStatusTransitionError - невозможный переход статусов (код 409)
- InvalidJobDataError - ошибка в данных (выбрала 422 код, а не 400, т.к. он предполагает логическую ошибку,  а не синтаксическую. В плане, что данные физически можно использовать, но в рамках предметной области - нельзя)
